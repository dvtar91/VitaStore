# 1. ROI миграции

## Вариант 1 — ROI на разовые инвестиции

Чистый эффект за три года:

```text
46,85 млн ₽
```

Разовые инвестиции:

```text
10,00 млн ₽
```

ROI:

```text
ROI = (46,85 / 10,00) × 100% = 468,5%
```

Такой показатель показывает размер накопленной экономии относительно стоимости проекта. Если использовать формулу, где из эффекта дополнительно вычитается инвестиция, необходимо сначала исключить проект из To-Be TCO, чтобы не вычесть его дважды:

```text
Экономия до стоимости проекта:
140,70 − (93,85 − 10,00) = 56,85 млн ₽

ROI = (56,85 − 10,00) / 10,00 × 100%
    = 468,5%
```

## Вариант 2 — ROI по совокупным затратам To-Be

```text
ROI = (140,70 − 93,85) / 93,85 × 100%
    = 49,9%
```

Для инвестиционного решения рекомендуется использовать первый вариант, поскольку он сопоставляет чистый эффект непосредственно с миграционным бюджетом.

# 2. Break-even point

Для окупаемости необходимо сравнивать разовую инвестицию с операционной экономией без её повторного учёта.

## Операционные затраты первого года без проекта

```text
To-Be год 1 без миграционного проекта:
43,97 − 10,00 = 33,97 млн ₽
```

Экономия первого года до инвестиции:

```text
59,30 − 33,97 = 25,33 млн ₽
```

Средняя месячная экономия:

```text
25,33 / 12 = 2,11 млн ₽ в месяц
```

Срок окупаемости:

```text
10,00 / 2,11 = 4,7 месяца
```

**Модельный break-even — около 5 месяцев от начала эксплуатации всех 100 магазинов.**

При поэтапном внедрении эффект возникает постепенно. Например, при равномерной миграции 100 магазинов в течение года среднее число работающих на новой платформе точек составит около 50, поэтому практический срок окупаемости будет ориентировочно **9–12 месяцев от старта программы**.

# 3. Итоговый вывод

Переход экономически выгоден:

- трёхлетний TCO снижается с **140,7 млн ₽ до 93,85 млн ₽**;
- абсолютная экономия составляет **46,85 млн ₽**;
- снижение совокупного TCO — **33,3%** с учётом проекта миграции;
- регулярные расходы после перехода снижаются примерно на **38,7%**;
- модельный ROI миграции — **468,5%**;
- окупаемость при одновременном переводе 100 магазинов — около **5 месяцев**;
- при реалистичном поэтапном rollout — примерно **9–12 месяцев**.
